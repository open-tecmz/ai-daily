> 在 AI 的噪音里，挑出真正好用的软件。

**AI 好用集**是一份由社区共同维护的软件推荐周刊。每一期收录若干款在 AI 时代真正提升效率的工具 —— 可能是 AI 产品，也可能是被 AI 重新点亮的经典软件。每一条推荐都要求推荐人自己用过，并说明它到底解决了什么问题。

灵感来自 [阮一峰的网络日志 · 科技爱好者周刊](https://github.com/ruanyf/weekly)：内容用 Markdown 维护，推荐通过 GitHub Issue 提交，编辑实测后整理成期发布。

---

## 为什么做这个

AI 让软件的供给爆炸了：每天都有新的 "AI + 某场景" 产品上线，但其中大多数只是套壳、演示或营销页面。真正能留下来、每天被打开的工具，反而很难被看见。

这个项目想做的事很朴素：

- **少而准**：宁缺毋滥，一期只放经过实测的几款，不做产品清单搬运。
- **说人话**：不写发布会式的功能介绍，只写"我在什么场景下用它，它替我做了什么"。
- **可追溯**：每一条推荐都来自具体的提交 Issue，读者可以看到它被谁推荐、为什么被收录。
- **不收费**：不接受付费收录、软文和返佣，广告位永远为空。

## 一期里有什么

每一期包含四个部分：

| 部分 | 内容 |
| --- | --- |
| 本期话题 | 一段编辑手记，聊聊最近值得注意的变化或一个具体的使用场景 |
| 本期推荐 | 5–8 款软件，每款一段推荐语、适用平台与价格 |
| 读者推荐 | 来自 Issue 的推荐中，编辑实测后认为值得一试的条目 |
| 上期回顾 | 上一期里被读者继续讨论、补充用法的软件 |

推荐条目的样子：

```markdown
### [Raycast](https://www.raycast.com/)

> 把 macOS 上散落的一切，收进一个快捷键。

**平台**：macOS　**价格**：免费 / Pro $8 月起　**关键词**：启动器、AI、效率

按下 ⌥ + 空格，搜索应用、文件、剪贴板历史、窗口管理，
再到翻译、脚本和 AI 对话。它的价值不在于功能多，而在于
你不需要再记第二套快捷键 —— 所有扩展都遵循同一套交互。

**适合谁**：每天在十几个工具之间来回切换的人。
**注意**：重度依赖扩展生态，团队协作场景偏弱。
```

## 推荐一款软件

不需要会写代码，会用 GitHub 就够了。整个流程只有三步：

1. 打开本仓库的 **Issues** 页面，点击 **New issue**。
2. 选择 **「推荐一款软件」** 模板，按提示填写。
3. 提交后等待编辑实测。收录与否、如何改写，都会在 Issue 里回复你。

仓库会同步到 GitHub、Gitee、GitCode 三个平台，三处都提供同一份表单，**在任意一处提交都可以**，编辑会统一汇总，不会重复刊登。

> 暂时不想注册 GitHub？也可以把推荐内容发到项目邮箱（待公布），由维护者代为提交。

### 推荐时请说明

| 字段 | 说明 | 是否必填 |
| --- | --- | --- |
| 软件名称 | 官方名称，不要用昵称或推广名 | ✅ |
| 官网 / 下载地址 | 优先官网，避免第三方下载站 | ✅ |
| 一句话介绍 | 30 字以内，说清它是做什么的 | ✅ |
| 解决了什么问题 | 具体场景，100 字以上，最好有"以前怎么做、现在怎么做"的对比 | ✅ |
| 平台 | macOS / Windows / Linux / iOS / Android / Web / 浏览器插件 / CLI | ✅ |
| 价格 | 免费 / 免费增值 / 付费，付费请注明大致价格 | ✅ |
| 使用时长 | 用了多久，是否每天都在用 | 建议 |
| 截图或录屏 | 一张能说明核心界面的图即可 | 可选 |
| 利益声明 | 是否为作者、员工、投资人或付费推广方 | ✅ |

### 编辑如何处理

- **实测**：编辑会亲自安装、跑通核心流程，而不是只看官网。
- **改写**：会按本项目的语气重写推荐语，可能删掉夸大表述。
- **去重**：同一款软件重复推荐会合并到首次收录的条目下。
- **不保证收录**：提交不等于刊登；不收录也会说明原因。
- **不收费**：任何形式的付费推广都不接受。

## 收录标准

**值得收录**

- 推荐人真实使用过，能说清具体使用场景
- 解决了明确的问题，或明显降低了某件事的门槛
- 有可用的免费入口，或定价清晰、不玩隐藏收费
- 官网可访问，更新活跃，不是一次性 Demo
- 对隐私、数据归属有基本交代

**不建议收录**

- 只有落地页、无法实际使用的产品
- 纯 API 套壳，换个界面就自称 AI 产品
- 依赖诱导分享、拉人头、返佣的模式
- 抓取或转卖他人数据、来源不明的工具
- 破解版、绿色版、盗版资源
- 与已收录条目高度重复且没有明显改进

### 新增一期

1. 在 `docs/` 下新建 `issue-001.md`，期号三位数、递增。
2. 开头写日期、本期话题，按「本期推荐 → 读者推荐」组织内容。
3. 配图放在 `images/001/`，使用相对路径引用。
4. 更新本文件顶部的「期号目录」。

### 撰写约定

- 中文正文，专有名词保留英文原名。
- 软件名首次出现时链接到官网，并给出平台与价格。
- 不写"最强""颠覆""革命性"这类词，写具体做了什么。
- 推荐语控制在 150 字以内；长文另开文档并在条目中链接。
- 每条推荐注明提交 Issue 编号，方便回溯。
